# Catálogo / Sistema de pedidos (.NET)

Solución de la prueba técnica en **C# / .NET 8** usando `List<>`.

## Parte 1 — Lógica
Dado `[3, 7, 2, 9, 7, 2, 5]`, encuentra el número que más se repite; si hay empate, el mayor → **7**.

## Parte 2 — Pedidos
Cada pedido tiene `id`, `cliente` y `total`, guardados en `List<Pedido>`:
- Crear
- Listar
- Obtener por id
- Eliminar
- Total general

## Cómo ejecutar

```bash
cd SistemaPedidos
dotnet run
```
